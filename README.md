#  Check-In

Proyecto web desarrollado con Laravel para la gestión integral de la asistencia y control de aprendices del SENA.

##  Módulos del sistema

- **Aprendices**: Registro completo de datos personales y ficha.
- **Asistencias**: Registro diario con filtros por fecha y ficha.
- **Justificantes**: Subida de soportes (PDF o imagen) y aprobación por el instructor.
- **Carnet Digital**: Generación de carnet con QR manual.
- **Registro de Equipos**: Registro del dispositivo personal del aprendiz.

## Características

- Autenticación con manejo dinámico de roles (Administrador, Instructor, Aprendiz).
- Dashboard con resumen e indicadores por módulo.
- Reportes filtrables por ficha, fecha, asistencia y más.
- Validaciones de formularios y buena usabilidad.
- Subida de archivos como soporte de justificación.
- Código QR en carnets (manual).

## Tecnologías utilizadas

- PHP 8.2.12
- Laravel 5.12.2
- MySQL
- Bootstrap / Tailwind
- Git y GitHub

##  Metodología

Se aplica **Scrum** con documentación en **JIRA** y control de versiones en GitHub.

##  Estructura

El proyecto sigue una estructura modular y se basa en el patrón MVC de Laravel.
